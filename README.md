# AURA VPN — чистая версия

Статический сайт без сборщика: `index.html` + `style.css` + `script.js`.

## GitHub Pages

1. Распакуйте архив.
2. Загрузите файлы в корень репозитория GitHub.
3. В Settings → Pages выберите публикацию из нужной ветки и `/ (root)`.
4. Откройте выданный GitHub Pages адрес.

## Важно

Покупка и VPN-конфигурация в этой версии работают в демо-режиме. Для реальных платежей и выдачи персональной серверной конфигурации потребуется серверная часть/API. Не размещайте приватные ключи сервера в публичном GitHub-репозитории.
